### MCP-инструменты в Clippy

- Добавлено подключение к одному MCP-серверу по HTTP, в том числе в локальной сети.
- В Settings появился раздел **MCP tools**: включение, HTTP endpoint, необязательный Bearer-токен, **Save and test MCP** и список доступных инструментов.
- Clippy передаёт модели описания MCP-инструментов и обрабатывает потоковые tool calls.
- Перед каждым вызовом появляется диалог с именем инструмента и JSON-аргументами. **Run tool** выполняет вызов, **Decline** передаёт отказ модели без выполнения.
- Результат инструмента возвращается модели для подготовки ответа. Количество раундов ограничено; отмена сообщения прерывает ожидание.
- Токен MCP хранится в Windows Credential Locker отдельно от ключа модели.
- Сохранены трей, положение в углу и ползунок размера Скрепки 60–200% из v0.2.0.

### Подключение

Включите MCP в Settings, укажите полный endpoint, например `http://192.168.1.10:3001/mcp`, и нажмите **Save and test MCP**.

Для llama.cpp используйте модель с поддержкой function calling и запустите сервер с `--jinja`, например:

```sh
llama-server -m /path/to/model.gguf --host 0.0.0.0 --port 8080 --alias local-model --jinja
```

Первая версия поддерживает HTTP MCP tools. Локальные stdio-процессы, MCP resources/prompts и OAuth-вход пока не поддерживаются.

### Установка и проверка

Скачайте `Clippy-win-x64.zip`, распакуйте весь архив и запустите `Clippy.exe`. Перед обновлением завершите старую версию через **Exit**. Существующие настройки сохраняются.

37 автоматических проверок проходят: подключение к модели, настройки, положение окна, MCP handshake/session/token, обнаружение и вызов инструментов, потоковые tool calls и отказ от выполнения. Windows Release-сборка проверяется GitHub Actions. Работа интерфейса и конкретной модели на реальном Windows-компьютере требует пользовательской проверки.
