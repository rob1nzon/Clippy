### Голосовой ввод через GigaAM

- В Settings добавлена галка **Голосовой ввод (GigaAM)**, по умолчанию выключенная.
- Настраиваются отдельный полный URL распознавания, STT model / alias и необязательный ключ. Адрес не связан с сервером чат-модели. Ключ хранится отдельно в Windows Credential Locker.
- После включения в панели чата появляется микрофон. Нажмите один раз для записи, повторно — для остановки и распознавания. Максимум 60 секунд; постоянного прослушивания нет.
- Распознанный текст дописывается в поле ввода. Сообщение не отправляется автоматически. Запись и распознавание можно отменить крестиком; скрытие или сворачивание чата, сброс диалога, выключение опции и изменение STT-настроек отменяют сеанс.
- Отправка сообщения, скриншот и Advice now блокируются на время голосового ввода, чтобы запросы не пересекались.

### API и приватность

Укажите полный HTTP endpoint, например `http://192.168.1.10:8000/v1/audio/transcriptions`. Clippy не дописывает путь автоматически. Поддерживается multipart POST с полями `file` (WAV 16 kHz, 16-bit mono), `model`, `response_format=json`; ожидается JSON `{"text":"распознанный текст"}`.

GigaAM как отдельная Python-модель или программа без такого HTTP API напрямую не подключается; нужен совместимый сервер-обёртка. Другие форматы API, SSE и WebSocket в этой версии не поддерживаются.

Используется микрофон по умолчанию Windows. Если запись не начинается, проверьте Settings → Privacy → Microphone и доступ для desktop apps. Аудио не записывается на диск; сервер может сохранять уже полученную запись. Используйте доверенный сервер.

### Установка и проверки

Закройте старую версию через **Exit**, распакуйте весь архив и запустите `Clippy.exe`. Настройки сохраняются. Добавлены проверки WAV, multipart-запроса, URL, ключа, лимитов, отмены и отсутствия автоматической отправки. Микрофон и конкретный сервер GigaAM требуют проверки на реальном Windows-компьютере.
