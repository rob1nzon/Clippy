### Минимальная анимация Скрепки

- Добавлено плавное покачивание: наклон примерно ±1°, подъём до 1,5 пикселя за пятисекундный цикл.
- При наведении Скрепка мягко приподнимается на 2 пикселя и чуть наклоняется; после ухода мыши плавно возвращается к покачиванию.
- Анимируется только картинка, не размер и положение окна. В области окна зарезервирован небольшой отступ, чтобы края картинки не обрезались при максимальном размере. Пустые участки экрана по-прежнему пропускают клики.
- В Settings → Personalisation Options появилась галка **Clippy animation**, включённая по умолчанию. Учитываются «Эффекты анимации» Windows; при выключении картинка неподвижна.
- При скрытии окна анимация останавливается, при повторном открытии возобновляется. Новые спрайты, GIF и фоновые таймеры кадров не нужны.

### Обновление

Закройте Clippy через **Exit**, выполните `scoop update`, затем `scoop update clippy`. Настройки сохраняются. Для ручной установки распакуйте ZIP целиком.

Добавлены проверки условий запуска, сохранения выключателя и геометрического запаса при максимальном размере. Windows-сборка проверяется GitHub Actions. Плавность и визуальный результат требуют проверки на реальном Windows-компьютере.
