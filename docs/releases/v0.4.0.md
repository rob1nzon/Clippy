### Необязательные советы по экрану

- В Settings добавлен режим **Optional screen advice**, выключенный по умолчанию. Включается только после сохранения и подтверждения отправки скриншотов на указанный сервер.
- Интервал 5–60 минут, по умолчанию 15. **Advice now** позволяет проверить работу сразу: Скрепка должна быть видна, а чат свёрнут.
- Скриншот только монитора со Скрепкой, JPEG с длинной стороной до 1280 пикселей. Снимки остаются в памяти, не записываются на диск и не добавляются в историю чата.
- Короткий совет на русском появляется рядом со Скрепкой на 25 секунд, без открытия чата и перехвата фокуса. Повторы подавляются; совет можно закрыть крестиком.
- Съёмка приостанавливается при скрытой Скрепке, активном чате/вводе, недоступном или заблокированном рабочем столе и полноэкранном приложении. Ошибка приостанавливает автоматические запросы до ручного повтора или изменения настроек.
- Выключение отменяет текущий запрос и убирает совет. Смена URL сервера выключает режим, требуя нового согласия. В запросах советов нет MCP-инструментов.

### Модель и приватность

Нужна модель, поддерживающая изображения. Для локальных файлов llama.cpp запустите vision-модель с соответствующим `--mmproj` и укажите её alias в настройках подключения.

Скриншот может содержать пароли, переписку и документы. Автоматического скрытия личных данных перед отправкой нет. Сервер может сохранять изображения; используйте только доверенный сервер. Выключение режима не удаляет уже отправленные данные с сервера.

### Установка и проверки

Завершите старую версию через **Exit**, распакуйте весь архив и запустите `Clippy.exe`. Настройки сохраняются, новый режим по умолчанию выключен.

Добавлены проверки vision-запроса, отсутствия MCP и истории, интервала, повторов, ошибок, отмены и выключения. Windows-сборка проверяется GitHub Actions. Захват настоящего рабочего стола, визуальное отображение совета и работа конкретной vision-модели требуют проверки на пользовательском Windows-компьютере.
