### System prompt, иконка и автозагрузка

- В Settings появился многострочный **System prompt** с кнопками сохранения и восстановления значения по умолчанию.
- Сохранённая инструкция применяется со следующего сообщения, без сброса истории. Пустой prompt отключает системную инструкцию. Отдельная фиксированная инструкция автоматических советов по экрану не меняется.
- По умолчанию: `You are in an app that revives Microsoft Clippy in Windows. Speak in a Clippy style`.
- Иконка существующей Скрепки встроена в EXE, установлена для главного окна и Settings; тот же ICO используется треем.
- Галка **Run on startup** теперь работает для portable EXE: запускает Clippy при входе текущего пользователя в Windows, через отдельную запись HKCU Run. По умолчанию запись отсутствует. Выключение удаляет только запись Clippy LAN.
- Для установки Scoop автозагрузка использует путь `apps\clippy\current\Clippy.exe`, который сохраняется при обновлениях.

### Обновление

Закройте Clippy через **Exit**, выполните `scoop update`, затем `scoop update clippy`. Для ZIP распакуйте весь архив и используйте `Clippy.exe` из новой папки. Настройки сохраняются.

Включите **Run on startup** в Settings. Если раньше создавали отдельный ярлык в `shell:startup`, уберите его вручную, чтобы не запускать вторую копию. Перед удалением приложения отключите **Run on startup**; удаление файлов само по себе не удаляет эту запись Windows.

Добавлены проверки замены и сохранения prompt, сохранения истории, пустой инструкции, регистрации/удаления автозагрузки и стабильного пути Scoop. Windows Release-сборка проверяет наличие ICO. Фактический запуск после входа в Windows и внешний вид иконок требуют проверки на пользовательском компьютере.
