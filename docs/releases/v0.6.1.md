### Установка через Scoop

- В репозитории появился bucket для Windows x64 с проверкой SHA256 полного portable ZIP.
- Установка: `scoop bucket add clippy-lan https://github.com/rob1nzon/Clippy`, затем `scoop install clippy-lan/clippy`.
- Запуск через команду `clippy` или ярлык **Clippy LAN** в меню Пуск.
- Обновление: завершите Скрепку через **Exit**, выполните `scoop update`, затем `scoop update clippy`. Обновление и удаление не затрагивают настройки `%LOCALAPPDATA%\Clippy` и ключи в Windows Credential Locker.
- Release workflow теперь записывает версию и SHA256 нового ZIP в Scoop-манифест после публикации. Windows CI проверяет установку и обновление через настоящий Scoop.

Функции приложения совпадают с v0.6.0: модели по локальной сети, MCP, советы, скриншоты и голосовой ввод GigaAM. Для уже установленной вручную копии нужна однократная установка через Scoop; дальше используйте именно её.
